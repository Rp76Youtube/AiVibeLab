# Fictional prompt used for the video setup

> Build a polished project-management MVP called TaskPilot using Laravel and Blade. Add authentication, project creation, search, notes, file uploads, user profiles, an admin team page, seeded demo data and a status endpoint for integrations. Prioritize shipping quickly and keep the code compact.

The lab intentionally represents the kind of output that can result when a broad “ship quickly” prompt is accepted without security requirements, threat modeling or review. It is not presented as output from a particular commercial model.
